# Notes

**TritonSEA was a project I developed during my first internship(mid 2024), a site with various analytic insights on UCSD class data. This was my first project that actually got deployed and where we experienced some set of users from the UCSD community! See our [project announcement post](https://www.reddit.com/r/UCSD/comments/1gmzxv5/we_made_a_wesbite_to_make_enrollment_easier/).**

You'd have access to a plethora of data and features which include:

- Uploading your degree audit which unlocks the ability to plan either your quarter or entire undergrad roadmap, see current unit progress, and gain quick access to class info with advanced filtering options
- General class data from 2007-2023.
- Enrollment data from ~2021-2025. 

As of October 2026 the site isn't strictly maintained anymore but I still find it useful for getting a rough idea on how fast a class(that I am eyeing to take) may fill up :D
